Liquid Glass Design Philosophy:
- **Surface**: rgba(255,255,255,0.10) background, 1px solid rgba(255,255,255,0.20) border, 20px-32px backdrop blur.
- **Colors**: Obsidian (#08090D), Midnight (#101116), Graphite (#1B1D24).
- **Typography**: Inter/SF Pro based, fluid responsive.
- **Motion**: Purposeful, smooth transitions, respect prefers-reduced-motion.

**How to apply:** All UI components should use these glass tokens. Do not create transparent surfaces without blur or border highlights.
